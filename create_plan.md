## 1. ビジョン＆基本方針

### 1.1 背景とコアコンセプト
従来の「マチジカン！」はゲームの提案と個別ツール表示にとどまっていました。
本計画では、**「1台のスマートフォンを囲み、完全オフライン・道具ゼロでグループ全員が白熱対戦できるゲームマスター」** へと進化させます。

### 1.2 確定した4大設計原則
1. **完全対戦ゲームへの純化（No Mystery Games）**
   - 推理型（ウミガメのスープ等）など対戦・勝敗に不向きなゲームは排除し、全員で勝ち負けを競えるゲームに特化。
2. **完全オフライン＆1台完結（Zero-Dependency）**
   - 電波状況に関係なく、代表者1台のスマホを囲んで即座に対戦開始〜決着まで完結。
3. **ゲーム特性に合わせた完全自動最適化UI（Adaptive Match Engine）**
   - **リアル完結型（ちんちん侍等）**: 口頭テンポを崩さないよう手番操作は不要。脱落タップまたは勝者即選択の爆速操作。
   - **ツール連動型（山手線ゲーム等）**: 画面上部に特大お題/タイマーを配置し、下部で脱落/勝者を記録する統合ビュー。
4. **セッション通算成績システム（All-Day Arcade）**
   - 複数のゲームをハシゴしても「★ 通算勝利数」が自動累計され、その日の総合王者を競い合える。

## 3. データ構造＆セッション管理設計

### 3.1 型定義 (`src/types/session.ts` & `src/types/engine.ts`)

```typescript
// プレイヤー通算成績
export interface PlayerStats {
  id: string;
  name: string;
  totalWins: number;      // 通算勝利数 (★)
  matchCount: number;     // 参加マッチ数
}

// 通算セッションデータ
export interface SessionData {
  sessionId: string;
  players: PlayerStats[];
  lastUpdated: string;
}

// 対戦エンジン種別 (完全自動切替)
export type MatchEngineType =
  | "quick_elimination"   // リアル完結型 (ちんちん侍、ほうれん草、あぶりカルビ等)
  | "tool_assisted";     // ツール連動型 (山手線、マジカルバナナ、しりとり等)
```

### 3.2 永続化ストレージ戦略
- **キー**: `machajikan_session_v2`
- **リセット方針**: 基本は `localStorage` で永続保持 ＋ 画面上の「通算成績をリセット」ボタン（確認ダイアログ付き）で意図した時だけクリア。

## 5. 実装ロードマップ

### Phase 1: 通算成績＆セッション管理基盤
- `types/session.ts`（型定義）
- `GameSessionContext.tsx` & `useGameSession.ts`（★勝利数管理・localStorage永続化・リセット機能）
- トップ画面に通算スコアヘッダーバーを配置

### Phase 2: 対戦不向きゲームの整理
- `games.ts` から推理型（ウミガメのスープ、20の扉）等を除外し、完全対戦型タイトルのみに厳選
- 各ゲームに `matchEngineType: "quick_elimination" | "tool_assisted"` を割り当て

### Phase 3: 自動最適化対戦画面の実装
- `QuickEliminationView.tsx`（リアル完結型の脱落＆勝者即決）
- `ToolAssistedMatchView.tsx`（画面上部特大ツール＋下部脱落/勝者記録）
- `play/page.tsx` をエンジン自動切替構造へ改修

### Phase 4: 勝者表彰モーダル＆2大導線の完成
- `MatchWinnerModal.tsx`（紙吹雪、通算★+1、自動ランキング表示）
- 「🔄 もう1戦！（リベンジ）」および「🎲 次の対戦ゲームを選ぶ」ボタンの実装
